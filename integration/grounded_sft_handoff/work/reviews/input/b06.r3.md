TARGET (read only after step 2)

> Here is what to try when your printer isn't in the list.
> 1. Make sure the printer is turned on and connected to the PC, for example by USB, or to the same network as the PC if it is a wireless printer.
> 2. Open **Start**, then **Settings**, then **Bluetooth & devices**, then **Printers & scanners**.
> 3. Go to **Add a printer & scanner** and select **Add device**, then wait for the list to load.
> 4. If the printer doesn't appear, select **Add a new device manually** next to **The printer that I want isn't listed**.
> 5. Follow the instructions in the Add Printer window that opens.
> If you already tried Add device, you can go straight to step 4.
