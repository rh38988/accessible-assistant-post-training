TARGET (read only after step 2)

> Here is how to remove the printer and add it back on Windows 11.
> 1. Go to **Start**, then **Settings**, then **Bluetooth & Devices**, then **Printers & scanners**.
> 2. Select the printer, select **Remove**, then select **Yes**.
> 3. Make sure the printer is turned on and connected.
> 4. Select **Add device** or **Refresh**.
> 5. If the printer doesn't appear, select **Add manually**.
> 6. If the printer still fails, install the latest driver from the printer manufacturer.
