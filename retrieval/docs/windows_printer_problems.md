Printer will not print (Windows)

Run the printer troubleshooter in the Get Help app. Turn the printer off, unplug it for about 30 seconds, then turn it on again. Check the USB cable, or for a wireless printer make sure its wireless is on and it is on the same network as the computer. Clear stuck jobs in the print queue.
