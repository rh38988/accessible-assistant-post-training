If an iPhone will not connect to Wi-Fi

Check that the router is on and nearby and that other devices can connect. Make sure Wi-Fi is on and Airplane Mode is off. Restart the iPhone, and unplug and replug the router and modem. Resetting network settings is a last resort because it erases saved Wi-Fi passwords.
