# ny1b generation report

Sources used:
- TR-128: https://support.apple.com/en-us/HT204091
- TR-129: https://support.apple.com/en-us/guide/mac-help/blth1004/mac (readable by WebFetch)
- TR-130: https://support.apple.com/en-us/102660
- TR-131: https://support.apple.com/en-us/104955 (supplemented by https://support.apple.com/en-us/120758 for the iCloud Keychain steps used in TR-131-e and -r)
- TR-132: https://support.apple.com/kb/HT212017 (the page https://support.apple.com/en-us/101603 only links to it and has no button steps)
- TR-133: https://support.apple.com/guide/iphone/report-spam-and-block-senders-iph3f94d910d/ios (needed fetching with offset 100000)

Backups used: none.

Uncertain points:
- TR-131: the page has no way to add a password manually, so the task was narrowed to finding saved passwords and keeping them in sync with iCloud Keychain. Steps for iCloud Keychain come from the 120758 page.
- TR-133: the source does not say what happens to the conversation after Delete and Report Spam, so in tr133-c and tr133-d the reply blocks first, then reports from the message list. The ordering is my choice, not stated by the source.
- TR-129-e: "Bluetooth status icon in Control Center" is stated by the page; it does not say whether the device must already be paired.
- TR-130-e: two-week lowering of security and the "can't be removed" note come from the page, but the page does not explain exactly which accounts qualify.
- TR-132-r: "you may need to get it serviced" follows the page's statement that Apple says you may need service if it still does not work after charging.
